# Gazebo Robot Simulation

A ROS 2 Jazzy package for simulating robots in Gazebo.

## Requirements

- ROS 2 Jazzy
- Gazebo Harmonic

## Installation

Install the required dependencies:

```bash
sudo apt install ros-jazzy-turtlebot3*
```

```bash
export TURTLEBOT3_MODEL=waffle
```

## Usage

Build the workspace:

```bash
cd ~/robotics/diff_ws
colcon build
source install/setup.bash
```
